UltraBlur

Serves Plex-identical 4-corner ambient colors extracted from item artwork by a bit-exact in-process port of Plex's algorithm. With the client script enabled, detail pages get a Plex-style ambient gradient with no theme edits. Native clients fetch GET /UltraBlur/Colors/{itemId} with standard auth.

Cap on simultaneous image extractions. Default: 4.
Injects the UltraBlur script into jellyfin-web to paint the ambient gradient on detail pages. Disable if you paint the gradient from a custom theme instead.
Precompute colors for library items on a daily schedule so detail pages get instant cache hits.
Most-recently-added items considered per warm-up run. Default: 500.
